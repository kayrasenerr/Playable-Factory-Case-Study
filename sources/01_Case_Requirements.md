## Scope traps

The 5.1 studio-size restriction is specific to that prospecting task; Task 1 does not explicitly impose it. Reusing an eligible smaller studio keeps the narrative simpler. Task 3's named games need not satisfy prospect criteria. Task 2's one-page limit does not justify omitting gaming/non-gaming application. Task 4 is text only, so do not spend time coding it. Task 1 needs a basic visual mockup, not a production playable. The manual does not require a deployed website, Unity project, real paid campaign or operational Sensor Tower integration.

## Timing conflict

The opening gives two days; the submission section says within three days. Confirm the actual deadline with the recruiter if feasible. Until resolved, work to a two-day completion target. Do not invent a due date from the upload date.

## Evidence vocabulary

Tag working statements FACT (source), CALCULATION (inputs/formula), OBSERVATION (directly seen), HYPOTHESIS (possible cause), PROPOSAL (recommended action), or UNKNOWN. Remove internal tags in polished prose only when the distinction remains clear. A proposal does not need proof that it will succeed, but it needs a stated mechanism and a way to test it.
